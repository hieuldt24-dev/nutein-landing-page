## Scope

Staff inbox for customer contact-form submissions. Covers reviewing, responding to, and managing
inbound contact messages. Distinct from the `contact` feature, which covers the public submission
side.

## Key Source Files

- `features/admin-contact/services/` -- contact submission data access
- `app/(staff)/staff/contact` -- staff contact inbox route
- `app/api/staff/contact` -- staff contact API
